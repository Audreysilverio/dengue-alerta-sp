# 🦟 Dengue Alerta SP

### Dados, tecnologia e prevenção contra a dengue em São Paulo

Uma plataforma interativa de visualização e análise de dados epidemiológicos e climáticos para apoiar a compreensão da dengue no município de São Paulo e fortalecer a conscientização sobre a prevenção das arboviroses.

## 🌎 Sobre o projeto

O **Dengue Alerta SP** é um projeto desenvolvido no contexto do Projeto Integrador da Universidade Virtual do Estado de São Paulo (UNIVESP), com foco na aplicação da tecnologia e da análise de dados a um problema de saúde pública.

A plataforma reúne informações epidemiológicas e climáticas em uma interface intuitiva, permitindo explorar indicadores, acompanhar tendências e compreender a relação entre fatores ambientais e a ocorrência da dengue.

O projeto também tem como referência territorial o Parque Vila Maria, articulando a análise de dados municipais com a percepção da comunidade sobre a dengue e as práticas de prevenção.

## 🎯 Objetivos

- Apresentar indicadores epidemiológicos de forma acessível.
- Explorar dados climáticos relacionados à precipitação, temperatura e umidade.
- Facilitar a visualização de informações por meio de gráficos e mapas interativos.
- Incentivar a conscientização e a prevenção da dengue.
- Demonstrar como dados e tecnologia podem contribuir para a compreensão de desafios da saúde pública.

## ✨ Funcionalidades

- **Dashboard interativo:** visão geral dos indicadores e informações relevantes.
- **Visualização de dados:** gráficos para explorar notificações e variáveis climáticas.
- **Mapa interativo:** representação geográfica de informações relacionadas à dengue.
- **Análise climática:** acompanhamento de precipitação, temperatura e umidade.
- **Backend em Node.js:** organização e disponibilização dos dados por meio de endpoints da API.

## 🚀 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- npm instalado

### 1. Clone o repositório

```bash
git clone https://github.com/Audreysilverio/dengue-alerta-sp.git
cd dengue-alerta-sp
```

### 2. Instale as dependências do frontend

```bash
npm install
```

### 3. Instale as dependências do backend

```bash
cd server
npm install
```

### 4. Inicie o servidor

```bash
npm start
```

Caso o `server/package.json` não tenha um script `start`, confira os scripts disponíveis e execute o comando correspondente.

### 5. Inicie o frontend

Em outro terminal, na pasta raiz do projeto:

```bash
npm run dev
```

O Vite exibirá o endereço local para abrir a aplicação no navegador.

## 📊 Dados e escopo

A análise epidemiológica utiliza dados referentes ao município de São Paulo. Como as bases oficiais disponíveis não permitem um recorte específico para o Parque Vila Maria, a análise de notificações foi ampliada para o município, mantendo o Parque Vila Maria como território de referência para a pesquisa comunitária.

Os dados climáticos são utilizados para explorar variáveis ambientais, como chuva, temperatura e umidade, sem pressupor causalidade direta.
